# 🛠️ TTT Editor Configuration

Configuración y plugins para [TTT Editor](https://github.com/eugenioenko/ttt) (Terminal Text Tool), IDE integrado para la terminal.

## Ubicación de archivos
* Directorio de configuración: `~/.config/ttt/`
* Plugins en Lua: `~/.config/ttt/plugins/`

## Integración con Herdr
TTT está integrado con el multiplexor Herdr mediante el plugin `ttt.editor`:
* Atajo en Herdr: `prefix + e`
* Comando CLI: `ttt .` o `ttt <archivo>`
